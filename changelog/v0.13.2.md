Luvus v0.13.2 keeps the terminal usable after the final project closes, adds native Muse and Oh My Pi support, expands Files and copy controls, and improves Windows server recovery. Existing v0.13.1 workspaces, settings, and sessions remain compatible after upgrading.

## Features

- **Workspaces:** Continue in a normal terminal rooted at Home after closing the final project instead of exiting Luvus ([`90b0319`](https://github.com/RizRiyz/luvus/commit/90b0319), [#179](https://github.com/RizRiyz/luvus/pull/179)).
- **Agents:** Detect, resume, and fork native Muse and Oh My Pi sessions with first-class lifecycle and usage integration ([`d43f17e`](https://github.com/RizRiyz/luvus/commit/d43f17e), [#172](https://github.com/RizRiyz/luvus/pull/172), [`29ec5f7`](https://github.com/RizRiyz/luvus/commit/29ec5f7), [#125](https://github.com/RizRiyz/luvus/pull/125)).
- **Files:** Choose how clicks open files and insert a selected file or folder path directly into the focused pane ([`e921eeb`](https://github.com/RizRiyz/luvus/commit/e921eeb), [#164](https://github.com/RizRiyz/luvus/pull/164), [`f193567`](https://github.com/RizRiyz/luvus/commit/f193567), [#168](https://github.com/RizRiyz/luvus/pull/168)).
- **Copying:** Double-click paths, URLs, or words to copy them and navigate copy mode with word-end, half-page, and count motions ([`c96b8b5`](https://github.com/RizRiyz/luvus/commit/c96b8b5), [#143](https://github.com/RizRiyz/luvus/pull/143), [`322ba06`](https://github.com/RizRiyz/luvus/commit/322ba06), [#148](https://github.com/RizRiyz/luvus/pull/148)).
- **Notifications:** Choose Soft, Pulse, or Retro sound styles for completed and blocked agents ([`bca9261`](https://github.com/RizRiyz/luvus/commit/bca9261), [#171](https://github.com/RizRiyz/luvus/pull/171)).
- **Mission Control:** Open Mission Control from the prefix legend, keyboard, CLI, or UHP automation ([`ea5061f`](https://github.com/RizRiyz/luvus/commit/ea5061f), [#157](https://github.com/RizRiyz/luvus/pull/157), [`719b1d2`](https://github.com/RizRiyz/luvus/commit/719b1d2), [#140](https://github.com/RizRiyz/luvus/pull/140)).
- **Korean:** Use the CLI, Settings, status text, and help in Korean as the ninth supported interface language ([`8f42c20`](https://github.com/RizRiyz/luvus/commit/8f42c20), [#159](https://github.com/RizRiyz/luvus/pull/159)).
- **Runtime logs:** Inspect bounded, private, redacted, and rotating diagnostic logs when troubleshooting Luvus ([`e73de19`](https://github.com/RizRiyz/luvus/commit/e73de19), [#137](https://github.com/RizRiyz/luvus/pull/137)).

## Improvements

- **Workspace mapping:** Follow pane directories and place nested Git worktrees in their own workspaces without blocking the interface ([`b740aeb`](https://github.com/RizRiyz/luvus/commit/b740aeb), [#158](https://github.com/RizRiyz/luvus/pull/158)).
- **Performance:** Share process snapshots, reduce the macOS SQLite footprint, and write runtime logs without dedicated threads or queues ([`6bdf9d0`](https://github.com/RizRiyz/luvus/commit/6bdf9d0), [#178](https://github.com/RizRiyz/luvus/pull/178), [`50319d1`](https://github.com/RizRiyz/luvus/commit/50319d1), [#156](https://github.com/RizRiyz/luvus/pull/156), [`bb047c0`](https://github.com/RizRiyz/luvus/commit/bb047c0), [#180](https://github.com/RizRiyz/luvus/pull/180)).
- **Sidebar:** Use compact scroll indicators and keep workspace branch labels display-only to prevent accidental actions ([`77e27e0`](https://github.com/RizRiyz/luvus/commit/77e27e0), [#175](https://github.com/RizRiyz/luvus/pull/175), [`26d8de3`](https://github.com/RizRiyz/luvus/commit/26d8de3), [#136](https://github.com/RizRiyz/luvus/pull/136)).
- **Mission pricing:** Use current Anthropic rates, real one-million-token windows, and correct Fable and Mythos 5 pricing ([`e9853db`](https://github.com/RizRiyz/luvus/commit/e9853db), [#134](https://github.com/RizRiyz/luvus/pull/134)).

## Fixes

- **Windows server:** Recover from unresponsive named pipes with bounded polling and a safe force-stop path ([`93635aa`](https://github.com/RizRiyz/luvus/commit/93635aa), [#147](https://github.com/RizRiyz/luvus/pull/147), [`b75afd4`](https://github.com/RizRiyz/luvus/commit/b75afd4), [#146](https://github.com/RizRiyz/luvus/pull/146)).
- **Windows agents:** Detect coding agents launched through npm shims instead of reporting only their wrapper process ([`f0c1330`](https://github.com/RizRiyz/luvus/commit/f0c1330), [#142](https://github.com/RizRiyz/luvus/pull/142)).
- **Terminal:** Avoid PTY startup panics, paragraph-motion errors, unbounded combining-mark growth, fullscreen wheel failures, and IME cursor placement on the working spinner ([`8ec52e9`](https://github.com/RizRiyz/luvus/commit/8ec52e9), [#173](https://github.com/RizRiyz/luvus/pull/173), [`9ee6401`](https://github.com/RizRiyz/luvus/commit/9ee6401), [#139](https://github.com/RizRiyz/luvus/pull/139), [`016ffa4`](https://github.com/RizRiyz/luvus/commit/016ffa4), [#145](https://github.com/RizRiyz/luvus/pull/145)).
- **Files:** Reuse an existing editor tab and preserve the selected dock side when Files is toggled ([`a0ce3b5`](https://github.com/RizRiyz/luvus/commit/a0ce3b5), [#161](https://github.com/RizRiyz/luvus/pull/161), [`5e8ad34`](https://github.com/RizRiyz/luvus/commit/5e8ad34), [#160](https://github.com/RizRiyz/luvus/pull/160)).
- **Menus:** Scroll long context menus so every action remains reachable in short terminals ([`636325e`](https://github.com/RizRiyz/luvus/commit/636325e), [#176](https://github.com/RizRiyz/luvus/pull/176)).
- **DIFF:** Keep sidebar and viewer scrolling aligned across wrapped, split, and narrow layouts ([`a1a03ee`](https://github.com/RizRiyz/luvus/commit/a1a03ee), [#153](https://github.com/RizRiyz/luvus/pull/153)).
- **Copying:** Restore linear multiline selection across terminal cells without including rectangular padding ([`1fb4bc3`](https://github.com/RizRiyz/luvus/commit/1fb4bc3), [#149](https://github.com/RizRiyz/luvus/pull/149)).
- **Grok:** Keep Grok marked Working while one of its subagents is still running ([`8bf83ed`](https://github.com/RizRiyz/luvus/commit/8bf83ed), [#150](https://github.com/RizRiyz/luvus/pull/150)).
- **Themes:** Preserve terminal transparency when Luvus starts with a terminal-derived theme ([`e553f0c`](https://github.com/RizRiyz/luvus/commit/e553f0c), [#167](https://github.com/RizRiyz/luvus/pull/167)).
