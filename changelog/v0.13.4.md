Luvus v0.13.4 adds named-session switching, direct shortcuts, remote UHP access, Hermes support, and keyboard-complete Files and DIFF workflows. Existing v0.13.2 Luvus settings and sessions remain compatible, while deprecated Bohay environment, state, module, and installer fallbacks are no longer supported.

## Features

- **Sessions:** Switch, start, and create named sessions from an on-demand desktop or mobile interface without detaching other clients ([`d382cf1`](https://github.com/RizRiyz/luvus/commit/d382cf1), [#224](https://github.com/RizRiyz/luvus/pull/224)).
- **Direct shortcuts:** Configure safe modified-key shortcuts that work without entering prefix mode, including direct Alt+Arrow tab switching ([`9f42ee5`](https://github.com/RizRiyz/luvus/commit/9f42ee5), [#230](https://github.com/RizRiyz/luvus/pull/230)).
- **Remote UHP:** Pair independent clients through a bounded foreground gateway, discover event schemas, and control Mission Control, hosts, and named sessions ([`d1013d1`](https://github.com/RizRiyz/luvus/commit/d1013d1), [#199](https://github.com/RizRiyz/luvus/pull/199), [`a5a9575`](https://github.com/RizRiyz/luvus/commit/a5a9575), [#221](https://github.com/RizRiyz/luvus/pull/221), [`edf9cd3`](https://github.com/RizRiyz/luvus/commit/edf9cd3), [#211](https://github.com/RizRiyz/luvus/pull/211)).
- **Agents:** Detect, monitor, resume, and install the Luvus skill for native Hermes CLI sessions ([`14da261`](https://github.com/RizRiyz/luvus/commit/14da261), [#193](https://github.com/RizRiyz/luvus/pull/193)).
- **Files:** Navigate the tree entirely by keyboard, open folders as workspaces, and send clicked terminal paths to the configured file destination ([`b3c472b`](https://github.com/RizRiyz/luvus/commit/b3c472b), [#208](https://github.com/RizRiyz/luvus/pull/208), [`2e94ce2`](https://github.com/RizRiyz/luvus/commit/2e94ce2), [#183](https://github.com/RizRiyz/luvus/pull/183), [`bc33b94`](https://github.com/RizRiyz/luvus/commit/bc33b94), [#186](https://github.com/RizRiyz/luvus/pull/186)).
- **Document previews:** Render Markdown and Mermaid as reusable terminal-native previews with navigation, search, and selection ([`0c24d8e`](https://github.com/RizRiyz/luvus/commit/0c24d8e), [#192](https://github.com/RizRiyz/luvus/pull/192)).
- **DIFF:** Open, navigate, filter, refresh, and act on changes entirely from the keyboard ([`26a4238`](https://github.com/RizRiyz/luvus/commit/26a4238), [#212](https://github.com/RizRiyz/luvus/pull/212)).
- **ORCH:** Run tasks in isolated worktrees or existing workspaces and control their complete lifecycle from the responsive board ([`e49f7b2`](https://github.com/RizRiyz/luvus/commit/e49f7b2), [#210](https://github.com/RizRiyz/luvus/pull/210), [`d5bc3f5`](https://github.com/RizRiyz/luvus/commit/d5bc3f5), [#189](https://github.com/RizRiyz/luvus/pull/189)).
- **Pane appearance:** Let terminal applications detect the active background and follow later dark or light theme changes ([`337ef06`](https://github.com/RizRiyz/luvus/commit/337ef06), [#198](https://github.com/RizRiyz/luvus/pull/198)).

## Improvements

- **Shortcut reference:** Show every configurable and mode-specific shortcut in a complete scrollable `Prefix+?` overlay ([`3def34b`](https://github.com/RizRiyz/luvus/commit/3def34b), [#218](https://github.com/RizRiyz/luvus/pull/218)).
- **Agents sidebar:** Remember whether the Agents dock shows All or Active sessions across restarts and config reloads ([`9155d73`](https://github.com/RizRiyz/luvus/commit/9155d73), [#197](https://github.com/RizRiyz/luvus/pull/197)).
- **Settings:** Use consistent lettered tab markers that remain readable across fonts, languages, and narrow terminals ([`4b02abd`](https://github.com/RizRiyz/luvus/commit/4b02abd), [#188](https://github.com/RizRiyz/luvus/pull/188)).
- **Nix:** Build and run the flake on macOS with the correct nixpkgs SQLite dependency ([`b4fb6cb`](https://github.com/RizRiyz/luvus/commit/b4fb6cb), [#196](https://github.com/RizRiyz/luvus/pull/196)).
- **License:** Distribute current and future Luvus releases under Apache License 2.0 ([`a36cb98`](https://github.com/RizRiyz/luvus/commit/a36cb98), [#187](https://github.com/RizRiyz/luvus/pull/187)).
- **Luvus naming:** Remove deprecated Bohay environment variables, state migration, module manifests, installer aliases, and runtime fallbacks ([`ffa9345`](https://github.com/RizRiyz/luvus/commit/ffa9345), [#202](https://github.com/RizRiyz/luvus/pull/202)).

## Fixes

- **Terminal input:** Preserve Windows multiline paste, Alt+Backspace word deletion, Ctrl+Slash, and distinct Ctrl+Shift letter chords in nested applications ([`eca9eed`](https://github.com/RizRiyz/luvus/commit/eca9eed), [#228](https://github.com/RizRiyz/luvus/pull/228), [`e4078ee`](https://github.com/RizRiyz/luvus/commit/e4078ee), [#206](https://github.com/RizRiyz/luvus/pull/206), [`c1b06cb`](https://github.com/RizRiyz/luvus/commit/c1b06cb), [#227](https://github.com/RizRiyz/luvus/pull/227), [`8f9f411`](https://github.com/RizRiyz/luvus/commit/8f9f411), [#229](https://github.com/RizRiyz/luvus/pull/229)).
- **Pane splitting:** Attach new panes to the requested workspace and tab when splitting a pane outside the active workspace ([`4732ec5`](https://github.com/RizRiyz/luvus/commit/4732ec5), [#216](https://github.com/RizRiyz/luvus/pull/216)).
- **Agent detection:** Parse padded process columns correctly and report visible Claude approval panels as blocked ([`001f5e6`](https://github.com/RizRiyz/luvus/commit/001f5e6), [#220](https://github.com/RizRiyz/luvus/pull/220), [`6f5d17c`](https://github.com/RizRiyz/luvus/commit/6f5d17c), [#209](https://github.com/RizRiyz/luvus/pull/209)).
- **Remote attach:** Find user-installed Luvus binaries when non-interactive SSH omits common installation directories from `PATH` ([`decacbf`](https://github.com/RizRiyz/luvus/commit/decacbf), [#222](https://github.com/RizRiyz/luvus/pull/222)).
- **Workspaces:** Keep explicitly closed launch folders closed when a client reattaches ([`3d7e9a1`](https://github.com/RizRiyz/luvus/commit/3d7e9a1), [#213](https://github.com/RizRiyz/luvus/pull/213)).
- **Copying:** Preserve logical line breaks, indentation, and soft wraps across terminal panes, files, and document previews ([`1aa08a2`](https://github.com/RizRiyz/luvus/commit/1aa08a2), [#201](https://github.com/RizRiyz/luvus/pull/201)).
- **Mission Control:** Select the exact visible agent session with one click without opening or resuming it ([`1abe95e`](https://github.com/RizRiyz/luvus/commit/1abe95e), [#190](https://github.com/RizRiyz/luvus/pull/190)).
