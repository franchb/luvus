Luvus v0.13.1 brings adaptive mobile controls, a redesigned Mission Control, UHP 1.0 automation, broader Agent Skills support, localized CLI and Settings interfaces, and faster change-driven rendering. Existing v0.12.0 workspaces and settings remain supported after upgrading.

## Features

- **Mobile:** Use a touch-friendly narrow-screen layout with fast navigation across agents, tabs, workspaces, settings, and session actions ([`515fa8c`](https://github.com/RizRiyz/luvus/commit/515fa8c), [#128](https://github.com/RizRiyz/luvus/pull/128)).
- **Mission Control:** Supervise agent sessions across workspaces with model, token, context, cost, lifecycle, and location details in a responsive full-tab dashboard ([`427bcb4`](https://github.com/RizRiyz/luvus/commit/427bcb4), [#119](https://github.com/RizRiyz/luvus/pull/119)).
- **UHP:** Automate sessions, terminals, agents, and harnesses through one discoverable UHP 1.0 contract with schemas, capabilities, events, bounded waits, and conformance fixtures ([`0bd3ee3`](https://github.com/RizRiyz/luvus/commit/0bd3ee3), [#96](https://github.com/RizRiyz/luvus/pull/96), [`d8ff137`](https://github.com/RizRiyz/luvus/commit/d8ff137), [#102](https://github.com/RizRiyz/luvus/pull/102), [`650c95b`](https://github.com/RizRiyz/luvus/commit/650c95b), [#108](https://github.com/RizRiyz/luvus/pull/108)).
- **Agent Skills:** Manage one release-matched Luvus skill across supported agent hosts and use machine-readable guides when building agent or harness integrations ([`40880ee`](https://github.com/RizRiyz/luvus/commit/40880ee), [#122](https://github.com/RizRiyz/luvus/pull/122), [`9219746`](https://github.com/RizRiyz/luvus/commit/9219746), [#123](https://github.com/RizRiyz/luvus/pull/123), [`99b26f9`](https://github.com/RizRiyz/luvus/commit/99b26f9), [#124](https://github.com/RizRiyz/luvus/pull/124)).
- **Codex plugin:** Install the versioned Luvus plugin source with its control skill, command guidance, and presentation assets ([`46c4867`](https://github.com/RizRiyz/luvus/commit/46c4867), [#101](https://github.com/RizRiyz/luvus/pull/101)).
- **CLI languages:** Read help and human-facing command output in English, Spanish, Portuguese, French, German, Indonesian, Simplified Chinese, or Japanese while commands and machine output stay stable ([`f8e6769`](https://github.com/RizRiyz/luvus/commit/f8e6769), [#126](https://github.com/RizRiyz/luvus/pull/126)).
- **Keybindings:** Choose safe function-key, Ctrl, or Alt command prefixes from Settings, including a no-Ctrl F12 preset ([`58cea57`](https://github.com/RizRiyz/luvus/commit/58cea57), [#104](https://github.com/RizRiyz/luvus/pull/104), [`aa380a6`](https://github.com/RizRiyz/luvus/commit/aa380a6), [#105](https://github.com/RizRiyz/luvus/pull/105)).
- **Agents:** Fork Grok Build sessions from the menu, keyboard, or CLI while keeping the original session running and command-family help focused ([`cb4ca0a`](https://github.com/RizRiyz/luvus/commit/cb4ca0a), [#107](https://github.com/RizRiyz/luvus/pull/107)).
- **Tabs:** Start new tabs and splits in the focused pane's current directory with a setting to retain the previous workspace-root behavior ([`9385ea6`](https://github.com/RizRiyz/luvus/commit/9385ea6), [#120](https://github.com/RizRiyz/luvus/pull/120)).
- **Folder picker:** Paste a path to jump directly to it and toggle hidden entries with the `.` key or footer control ([`a15ec50`](https://github.com/RizRiyz/luvus/commit/a15ec50), [#62](https://github.com/RizRiyz/luvus/pull/62), [`b7fa509`](https://github.com/RizRiyz/luvus/commit/b7fa509), [#114](https://github.com/RizRiyz/luvus/pull/114)).
- **Themes:** Choose from Anakmagang Dark, Edge Dark, Read Roomy, and Reedge Dark in the community theme registry ([`620352f`](https://github.com/RizRiyz/luvus/commit/620352f), [#100](https://github.com/RizRiyz/luvus/pull/100)).

## Improvements

- **Performance:** Render visible changes instead of repainting the full interface for hidden pane output or off-screen agent animation ([`a0575a8`](https://github.com/RizRiyz/luvus/commit/a0575a8), [#117](https://github.com/RizRiyz/luvus/pull/117)).
- **Extensibility:** Construct terminal engines through one shared factory so backend integrations use a consistent boundary without changing current Alacritty behavior ([`e08feac`](https://github.com/RizRiyz/luvus/commit/e08feac), [#109](https://github.com/RizRiyz/luvus/pull/109)).
- **Website:** Explore the composable Mission Control blog and watch compact release demos for DIFF, fuzzy search, themes, Luvus Bar, and tab reordering ([`a5bc7cb`](https://github.com/RizRiyz/luvus/commit/a5bc7cb), [#91](https://github.com/RizRiyz/luvus/pull/91), [`c304117`](https://github.com/RizRiyz/luvus/commit/c304117), [#98](https://github.com/RizRiyz/luvus/pull/98)).

## Fixes

- **Settings:** Translate built-in labels, actions, hints, key references, messages, and display values across all eight supported languages with correct alignment for CJK text ([`7ac7eed`](https://github.com/RizRiyz/luvus/commit/7ac7eed), [#131](https://github.com/RizRiyz/luvus/pull/131)).
- **Copying:** Keep selections attached to their original scrollback text and preserve CJK characters, combining marks, variation selectors, and emoji sequences when copying ([`d38c15b`](https://github.com/RizRiyz/luvus/commit/d38c15b), [#127](https://github.com/RizRiyz/luvus/pull/127), [`44e1e07`](https://github.com/RizRiyz/luvus/commit/44e1e07), [#130](https://github.com/RizRiyz/luvus/pull/130)).
- **Agent restore:** Keep resumed sessions bound to their original panes and show fork actions only when the pane has an exact session binding ([`5e7c0e8`](https://github.com/RizRiyz/luvus/commit/5e7c0e8), [#95](https://github.com/RizRiyz/luvus/pull/95)).
- **Codex:** Report native Codex sessions to the active server without colliding with Luvus session routing or leaving older hooks incomplete ([`dd6eaae`](https://github.com/RizRiyz/luvus/commit/dd6eaae), [#97](https://github.com/RizRiyz/luvus/pull/97)).
- **Server restore:** Replay saved pane content immediately, restore PTYs in the background, bound lifecycle waits, and avoid replacing a server that still owns its socket ([`92141f1`](https://github.com/RizRiyz/luvus/commit/92141f1), [#116](https://github.com/RizRiyz/luvus/pull/116)).
- **Modules:** Restore discovery through the canonical GitHub topic and provide copy controls for module installation commands ([`57451c7`](https://github.com/RizRiyz/luvus/commit/57451c7), [#99](https://github.com/RizRiyz/luvus/pull/99)).
- **Windows:** Stop PowerShell, Git, notification, and other child processes from flashing console windows while Luvus is running ([`13b1eb3`](https://github.com/RizRiyz/luvus/commit/13b1eb3), [#60](https://github.com/RizRiyz/luvus/pull/60)).
- **Windows input:** Type AltGr characters correctly in panes, search, switchers, and remote input without converting them into Ctrl chords ([`08ac195`](https://github.com/RizRiyz/luvus/commit/08ac195), [#61](https://github.com/RizRiyz/luvus/pull/61)).
- **Windows Git:** Apply repository status tinting when Git and the workspace use different path spellings ([`22b0c29`](https://github.com/RizRiyz/luvus/commit/22b0c29), [#63](https://github.com/RizRiyz/luvus/pull/63)).
- **Windows agents:** Discover Claude sessions across drive paths, spaces, punctuation, and non-ASCII project names ([`1f4694e`](https://github.com/RizRiyz/luvus/commit/1f4694e), [#64](https://github.com/RizRiyz/luvus/pull/64)).
